Somente leitura, neste computador. A página não grava notas e não guarda o resultado no aparelho.

Instalar no Android
  1. Deixe este processo aberto no computador.
  2. Com o cabo, rode o adb reverse na porta impressa no terminal.
  3. No Chrome do telefone, abra o link do terminal.
  4. No menu do Chrome, escolha Instalar app ou Adicionar à tela inicial.
